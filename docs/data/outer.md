## Trans-Neptunian objects: `public/data/outer/tnos.bin` + `tnos.json`

- **Source:** JPL Small-Body Database Query API, `sb-class=TNO` (orbits fitted to Minor Planet Center astrometry). SBDB is used instead of scraping the MPC distant-object pages: same orbit data, documented JSON API, stated reuse terms. Terms: U.S. Government (NASA/JPL-Caltech) public data service; no license or reuse restrictions are stated by JPL SSD/CNEOS. Use is governed by the JPL SSD/CNEOS API Fair Use Policy (one request at a time, application-specific User-Agent, cache results, no embedding of the APIs in websites per NASA CORS policy). Do not imply NASA/JPL endorsement.
- **Rows:** 7301 objects, brightest (smallest H) first, so a prefix is a valid brightness-limited subset. Float32 x 9: a [au], e, i, node, argPeri, M0 [deg], epoch offset [d from epochBaseJD 2461200.5], H [mag], class code.
- **Class counts:** {"scattered":1653,"plutino":669,"hot-classical":1651,"other":667,"detached":278,"twotino":261,"other-resonant":768,"cold-classical":1354}. The class is a heuristic box on osculating a, e, i (3:2 plutinos, 2:1 twotinos, other resonances, cold/hot classical split at i = 5 deg, scattered, detached) and is labelled *derived* in the app.
- **Limitations:** observational census (bright, near-ecliptic, near-perihelion bias); two-body propagation from per-object osculating elements.

## Provenance of the visuals

- TNO points: **observed** orbits (class colour and point size are visual cues).
- Heliosphere shells: **reconstructed**. A smooth surface r = R (1 + k s^p)(1 + a n.north) with s = (1 - cos theta)/2 about the nose; R and a are fitted so the surface passes through the four Voyager crossings, k and p (flank/tail elongation) are assumed. The tail is open, unconstrained and fades out.
- Voyager crossing markers: published distance along each craft's current heliocentric direction (the shipped Horizons trajectories cover only 2025-2030, and both craft move almost radially).
- Oort cloud: **illustrative** seeded random sample; no object is real.
- Light-hour / light-day / light-year rings: **derived** (c x time).
