# Cosmos media kit

Still images, clips and charts of Cosmos for the README, posters and the presentation. Every still was captured from the running app at Ultra quality, with real data and the real Sun direction, and no debug UI.

- Web copies: `docs/media/screens/*.webp` (desktop, 1920x1080 or 3840x2160 sources) and `docs/media/mobile/*.webp` (phone and tablet). WebP quality 85.
- Print originals (full-resolution PNG, not in the repo): `G:/CosmosWork/media-print/` (desktop) and `G:/CosmosWork/media-print/mobile/`.
- Sizes below are the print original; the web copy is the same frame at the same size unless noted.

## Charts

SVG with a solid background and embedded app fonts, so they read on GitHub light and dark. Rebuild with `node docs/media/charts/build-charts.mjs`.

- `charts/ladder.svg` - The golden journey on a log scale: real distances from Earth, ISS (400 km) to the cosmic microwave background (45 billion light-years); sources in the caption.
- `charts/inside.svg` - What's inside: catalogue sizes and sources, counted from `public/data` and `docs/data`.
- `charts/performance.svg` - Performance per view, from `.work/swarm/reports`.
